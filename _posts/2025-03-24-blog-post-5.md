## Overview

In this project, I trained a policy using **Proximal Policy Optimization (PPO)** in **Isaac Lab** to enable a UR5e robot arm to grasp a cube placed randomly within its workspace. The goal was to extend the previously trained point-reaching policy to a more complex **manipulation task involving contact, alignment, and precise gripper control**.

The environment was built on top of Isaac Lab’s reinforcement learning framework and utilizes GPU-accelerated physics simulation for high training throughput.


## Tools and Frameworks Used

- **Ubuntu 22.04**
- **Isaac Lab (based on Isaac Sim 4.5)**
- **skrl PPO implementation**
- **UR5e robot model**
- **Robotiq 2F-85 gripper model**

## Task Description

- **Goal:** Reach and grasp a static cube positioned randomly within a predefined area.
- **Observation space:**
  - Joint positions and velocities
  - End-effector pose
  - Cube pose
  - Gripper state
- **Action space:**
  - Joint position deltas (6-DoF)
  - Gripper open/close action
- **Reward function:**
  - Negative distance to cube
  - Bonus for successful grasp (based on lift detection)
  - Regularization terms for smooth movement and safe contact

## Implementation Steps

1. **Creating Manager External Project**
   - Initialized a new external project based on Isaac Lab's template.
   - Registered the custom environment and training configuration in the Isaac Lab registry.

2. **Environment Setup:**
   - Created the UR5e robot and Robotiq 2F-85 gripper for the usage of Isaac Lab, and implemented to the environment in place of the original UR10e robot.
   - Randomized initial cube position within a small planar region.

3. **Creating Observation and Action space:**
   - **Observations included:**
      - UR5e joint states
      - End-effector position + orientation
      - Cube position + relative pose
      - Gripper state
      - Target position relative to the robot's base
   - **Actions:**
      - Continuous joint position deltas
      - 1D gripper command

4. **Reward logic:**
   - Designed a dense reward function (the reward structure are shown below):
      - Negative Euclidean distance to the goal (scaled)
      - Bonus for success within a small threshold
      - Penalties for joint limit violation or excessive action magnitude
      - Distance to cube (tanh-scaled)
      - Bonus reward for successful grasp

5. **Training:**
   - Used 'skrl' PPO trainer backend integrated with Isaac Lab.
   - Tuned key hyperparameters, the hyperparameters are shown below.
   - Trained the policy on GPU for 36000 steps
   - Logged reward curves during training with tensorboard

6. **Evaluation**
   - Deployed the trained policy in evaluation mode

## Important PPO Hyperparameters

| Category             | Parameter                  | Value                   |
|----------------------|----------------------------|-------------------------|
| **General**          | Seed                       | 42                      |
|                      | Timesteps                  | 36,000                  |
| **Network (Policy)** | Layers                     | [256, 128, 64]          |
|                      | Activation                 | ELU                     |
| **Network (Value)**  | Layers                     | [256, 128, 64]          |
|                      | Activation                 | ELU                     |
| **Policy Model**     | Gaussian Log Std Range     | [-20.0, 2.0]            |
|                      | Initial Log Std            | 0.0                     |
| **Optimization**     | Learning Rate              | 1e-3                    |
|                      | Scheduler                  | KLAdaptiveLR (0.01)     |
|                      | Epochs per Update          | 5                       |
|                      | Mini-batches               | 4                       |
| **PPO Parameters**   | Rollouts                   | 24                      |
|                      | Discount Factor (γ)        | 0.99                    |
|                      | GAE Lambda (λ)             | 0.95                    |
|                      | Ratio Clip                 | 0.2                     |
|                      | Value Clip                 | 0.2                     |

## Reward structure

| Term Name                           | Description                                     | Weight   |
|-------------------------------------|-------------------------------------------------|----------|
| `reaching_object`                   | Encourages the end-effector to reach the object | 1.0      |
| `lifting_object`                    | Reward for lifting the object above threshold   | 15.0     |
| `object_goal_tracking`              | Reward for bringing object near commanded goal  | 16.0     |
| `object_goal_tracking_fine_grained` | Fine-grained reward near goal                   | 5.0      |
| `action_rate`                       | Penalizes large changes in joint commands       | -0.0001  |
| `joint_vel`                         | Penalizes high joint velocities                 | -0.0001  |

## Curriculum Adjustments

| Term         | Adjusted Weight | Steps     | Purpose                                   |
|--------------|-----------------|-----------|-------------------------------------------|
| `action_rate`| -0.1            | 10,000    | Stronger penalty early on for stability   |
| `joint_vel`  | -0.1            | 10,000    | Encourages slow, precise motion initially |

## Outcome

This project successfully demonstrated that PPO can be used to train a 6-DoF UR5e robot arm to perform a full grasping motion in simulation. The task introduces object interaction, contact handling, and gripper coordination — key ingredients for future manipulation research and sim-to-real transfer.
