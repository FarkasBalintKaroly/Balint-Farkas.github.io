## Overview

In this project, I successfully controlled a real UR5e collaborative robot arm using ROS2 and MoveIt2. The objective was to transfer the previously configured MoveIt2 setup from simulation to physical hardware, enabling real-time trajectory planning and execution in a lab environment.

The project represents a key milestone in moving from virtual testing to real-world robotic control, laying the foundation for future sim-to-real reinforcement learning applications.

## Tools and Frameworks Used

- **Ubuntu 22.04**
- **ROS2 Humble**
- **RViz2**
- **MoveIt2**
- **Universal_Robots_ROS2_Driver**

## Implementation Steps

1. **Hardware Preparation:**
   - Connected the UR5e robot and Robotiq 2F-85 gripper to the same LAN as the ROS2 workstation.
   - Verified network communication and robot availability using the assigned IP address.

2. **UR ROS2 Driver Setup:**
   - Installed and built the official ROS2 driver:
     - [Universal Robots ROS2 Driver GitHub Repository](https://github.com/UniversalRobots/Universal_Robots_ROS2_Driver)
   - Loaded the external control URCap on the robot.
   - Configured the robot’s IP address, safety mode, and control interface.

3. **Reusing the MoveIt2 Configuration:**
   - Used the same MoveIt2 config package as in Isaac Sim.
   - Ensured correct controller interfaces (`FollowJointTrajectory`) and planning group consistency.
   - Validated joint limits and reference frames.

4. **Launching the System:**
   - Brought up the robot driver and MoveIt2 planning interface:
     ```bash
     ros2 launch ur_bringup ur_control.launch.py ur_type:=ur5e robot_ip:=<ROBOT_IP>
     ros2 launch my_moveit_config demo.launch.py
     ```
   - Planned trajectories in RViz2 and executed them on the real robot.
   - Monitored joint states, TF, and controller feedback.

## Outcome

This project demonstrated reliable control of a physical UR5e robot arm through ROS2 and MoveIt2, mirroring the simulation setup. It confirmed that the existing planning configuration could be directly reused on real hardware with only minimal adjustments. The work is a major step toward full sim-to-real reinforcement learning integration.
