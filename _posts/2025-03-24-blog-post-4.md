## Overview

In this project, I used **Proximal Policy Optimization (PPO)** in **Isaac Lab** to train a UR5e robot arm to reach a fixed target point with its end-effector. The task serves as a minimal example of reinforcement learning (RL) applied to continuous control for robot manipulators, and it provides a foundation for more complex policy learning tasks such as grasping or trajectory tracking.

The policy was trained entirely in simulation, leveraging Isaac Lab’s high-fidelity physics, GPU-accelerated simulation backend, and modular RL environment structure.

The task was implemented by Isaac Lab for UR10e robot, so I recreated the environment with UR5e robot to understand the manager based project structure inside Isaac Lab.


## Tools and Frameworks Used

- **Ubuntu 22.04**
- **Isaac Lab (based on Isaac Sim 4.5)**
- **skrl PPO implementation**
- **UR5e robot model**

## Task Description

- **Goal:** The robot's end-effector must reach a predefined target position within the workspace.
- **Observation space:**
   - Joint positions and velocities
   - Target position
- **Action space:** Continuous joint position deltas (6-DoF)
- **Reward function:**
   - Negative Euclidean distance to target
   - Penalty for joint 

## Implementation Steps

1. **Creating Manager-Based External Project**
   - Initialized a new external project based on Isaac Lab's template.
   - Registered the custom environment and training configuration in the Isaac Lab registry.


2. **Environment Setup:**
   - Created the UR5e robot for the usage of Isaac Lab, and implemented to the environment in place of the original UR10e robot.

3. **Creating Observation and Action space:**
   - **Observations included:**
      - Joint positions and velocities
      - Target position relative to the robot's base
   - **Actions:**
      - Continuous joint position deltas

4. **Reward logic:**
   - Designed a dense reward function (the reward structure are shown below):
      - Negative Euclidean distance to the goal (scaled)
      - Bonus for success within a small threshold
      - Penalties for joint limit violation or excessive action magnitude

5. **Training:**
   - Used 'skrl' PPO trainer backend integrated with Isaac Lab.
   - Tuned key hyperparameters, the hyperparameters are shown below.
   - Trained the policy on GPU for 30000 steps
   - Logged reward curves during training with tensorboard

6. **Evaluation**
   - Deployed the trained policy in evaluation mode

## Important PPO Hyperparameters

| Category             | Parameter                  | Value                   |
|----------------------|----------------------------|-------------------------|
| **General**          | Seed                       | 42                      |
|                      | Timesteps                  | 30,000                  |
| **Network (Policy)** | Layers                     | [64, 64]                |
|                      | Activation                 | ELU                     |
| **Network (Value)**  | Layers                     | [64, 64]                |
|                      | Activation                 | ELU                     |
| **Policy Model**     | Gaussian Log Std Range     | [-20.0, 2.0]            |
|                      | Initial Log Std            | 0.0                     |
| **Optimization**     | Learning Rate              | 1e-3                    |
|                      | Scheduler                  | KLAdaptiveLR (0.01)     |
|                      | Epochs per Update          | 5                       |
|                      | Mini-batches               | 4                       |
| **PPO Parameters**   | Rollouts                   | 24                      |
|                      | Discount Factor (γ)        | 0.99                    |
|                      | GAE Lambda (λ)             | 0.95                    |
|                      | Ratio Clip                 | 0.2                     |
|                      | Value Clip                 | 0.2                     |

## Reward structure

| Term Name                                     | Description                            | Weight   |
|-----------------------------------------------|----------------------------------------|----------|
| `end_effector_position_tracking`              | Penalizes distance to target position  | -0.2     |
| `end_effector_position_tracking_fine_grained` | Encourages precise convergence         | 0.1      |
| `end_effector_orientation_tracking`           | Penalizes orientation error            | -0.1     |
| `action_rate`                                 | Penalizes fast changes in actions      | -0.0001  |
| `joint_vel`                                   | Penalizes high joint velocities        | -0.0001  |

## Outcome

This project demonstrated that PPO can successfully learn precise position control for a 6-DoF manipulator in Isaac Lab. The trained policy converged reliably to the target and laid the groundwork for generalizing to multi-goal tasks and more complex reward functions. This was my first implementation of robotic learning, I learned a lot from this implementation.
